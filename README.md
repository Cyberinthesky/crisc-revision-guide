# CRISC Revision Guide: All Domains & Topics

A free, 37-page revision guide for the **ISACA CRISC** (Certified in Risk and Information Systems Control) exam, covering all four domains of the current exam content outline.

**[⬇️ Download the PDF](CRISC_Revision_Guide_cyberinthesky.pdf)**

## What's inside

- Exam snapshot and the seven golden rules that answer most questions
- Briefs for all 31 topics across the four domains:
  1. Governance (26%)
  2. Risk Assessment (22%)
  3. Risk Response & Reporting (32%)
  4. Technology & Security (20%)
- For every topic: what to know, where it sits, common traps, a real-life example and a memory hook
- Key terms with one-line definitions
- Question tricks, key words and qualifier cues (FIRST, BEST, MOST, PRIMARY, GREATEST)
- "Which technique is best when" and "which report suits which audience" tables, with exam-style examples
- A worked cost-benefit example for choosing risk responses
- A map of every subtopic in the current exam content outline
- Common traps and an exam-day routine

## How to use it

Read one domain at a time, then practise with exam-style questions before moving on. Use it alongside ISACA's official review materials, not instead of them.
